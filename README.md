# Hospital Management Analysis

### Hospital Management Data Analysis using Excel, MySQL and Power BI

## 📌 Project Overview

This project analyzes hospital data to understand patient demographics, appointment trends, departments, doctors, appointment status, payment methods, and billing.

The project uses **Excel, MySQL, and Power BI** to clean, analyze, and visualize the data.

## 🛠️ Tools Used

- Microsoft Excel
- MySQL
- Power BI

## 📊 Dataset

The project contains two related datasets:

### Patients
- 1,000 patient records
- Patient demographics
- Age and age groups
- Blood groups
- Cities
- Registration dates

### Appointments
- 5,000 appointment records
- Departments
- Doctors
- Appointment types
- Appointment status
- Payment methods
- Bill amounts

The two tables are connected using **Patient_ID**.

## 🔍 Analysis Performed

### Excel
- Pivot Tables
- Patient demographic analysis
- Registration trends
- Department-wise appointments
- Doctor-wise appointments
- Appointment status analysis
- Payment method analysis
- Billing analysis

### MySQL
- Data querying
- Filtering and sorting
- Aggregate functions
- GROUP BY and HAVING
- Subqueries
- JOINs between Patients and Appointments

### Power BI
- Data modeling
- Table relationships
- KPI cards
- Interactive charts
- Patient analysis
- Appointment analysis
- Billing analysis

## 📈 Key Insights

- **5,000** total appointments
- **3,342** completed appointments
- **21.03 million** total bill amount
- **General Medicine** had the highest number of appointments with **1,031**
- **Dr. Ali** had the highest number of appointments with **564**
- **Routine Checkups** were the most common appointment type with **1,798**
- **Cash** was the most frequently used payment method with **1,702 transactions**
